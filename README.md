This project is a comprehensive Sales Dashboard built using Microsoft Excel. It analyzes sales data across multiple regions and countries, focusing on product categories (Fruit & Vegetables). The goal is to provide clear insights into revenue distribution, regional performance, and product trends to support data-driven decision-making.
Analysis Dimensions (Based on Data)

The dashboard provides answers to key business requirements using the following dimensions:

Sales Metrics: Calculated values for Total Sales, Number of Orders, and Average Sales per Country.
Geographic Analysis: Sales performance broken down by Region (East, West, North, South) and Country (US, UK, Canada, Germany, France, Australia, etc.).
Product Analysis: Total sales for each Category (Fruit, Vegetables)
Time Series: Tracking sales trends over Months and Years (2019 - 2020). by using interactive slicers.

Technical Features
Data Cleaning: Processed raw order data (Order ID, Date, Amount) to ensure accuracy.
Pivot Tables & Charts: Used for dynamic data aggregation and visualization of sales by region and category.
Interactive Design: Structured the layout to display high-level KPIs alongside detailed breakdown tables.
